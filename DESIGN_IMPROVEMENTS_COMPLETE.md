## 🎨 Système de Design

### **Palette de couleurs**
```css
--primary-color: #2563eb      /* Bleu principal */
--primary-light: #3b82f6      /* Bleu clair */
--secondary-color: #f59e0b    /* Orange */
--accent-color: #10b981       /* Vert */
--success-color: #059669      /* Vert foncé */
--warning-color: #d97706      /* Orange foncé */
--error-color: #dc2626        /* Rouge */
```

### **Typographie**
- **Police principale** : Inter (Google Fonts)
- **Hiérarchie** : 8 tailles de police (xs à 5xl)
- **Poids** : 300 à 800

### **Espacement**
- **Système cohérent** : 0.25rem à 5rem
- **Grille responsive** : Flexbox et CSS Grid
- **Marges et paddings** : Variables CSS

### **Ombres et effets**
- **5 niveaux d'ombres** : sm à xl
- **Bordures arrondies** : 6 tailles (sm à 2xl)
- **Transitions** : 3 vitesses (fast, normal, slow)
