# Démarrage rapide

1. JDK 25 (`brew install openjdk@25`)
2. Double-clic **`Démarrer.command`** → http://localhost:8080
3. Arrêt : **`Arrêter.command`**

```bash
./start.sh              # terminal
./start.sh --fg         # logs visibles
./stop.sh
```

Le reste (profils, deploy, calendrier) est dans le [README](README.md).
