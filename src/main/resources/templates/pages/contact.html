Questions fréquentes

Comment ajouter une nouvelle course ?

Utilisez le bouton "Ajouter une course" sur la page de sélection des courses. Vous devrez fournir un fichier Excel avec les résultats.

Quels formats de fichiers sont acceptés ?

Nous acceptons les fichiers Excel (.xls et .xlsx) contenant les résultats des courses.

Comment consulter les championnats ?

Accédez à la page "Championnat" depuis le menu de navigation pour voir les classements.

Le site est-il compatible mobile ?

Oui, le site est entièrement responsive et s'adapte à tous les appareils : ordinateur, tablette et mobile.
